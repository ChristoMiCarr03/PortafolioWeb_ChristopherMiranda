# Portafolio Web Profesional

## Objetivo del Proyecto
Diseñar e implementar una plataforma web modular, autogestionable y con altos estándares de diseño UX/UI que funcione como una infraestructura digital centralizada para exponer competencias, servicios informáticos y desarrollos técnicos.

## Problema que Resuelve
La falta de visibilidad y la complejidad para centralizar y mostrar el historial de proyectos, tecnologías dominadas y formas de contacto de un ingeniero frente a reclutadores del sector tecnológico de una manera interactiva y profesional.

## Tecnologías Utilizadas
* **Plataforma Base:** WordPress (CMS - Sistema de Gestión de Contenidos).
* **Diseño y Maquetación:** Tema *Sunbrake* y Constructor Visual de Bloques *Kubio*.
* **Tecnologías Web Complementarias:** HTML5, CSS3 (Estructuras Flexbox y Media Queries).

## Conceptos Aplicados
* **Diseño Responsivo Avanzado:** Adaptación fluida de la cuadrícula de contenidos en base a puntos de ruptura (*breakpoints*) para garantizar legibilidad en teléfonos, tabletas y ordenadores.
* **Estrategia Low-Code / No-Code:** Aprovechamiento de sistemas de gestión de contenido para acelerar los tiempos de despliegue informático sin sacrificar el control sobre las hojas de estilo y estructuras.
* **Arquitectura de Información Centrada en el Usuario (UX):** Distribución estratégica de contenido en secciones semánticas (*Home, Sobre Mí, Portafolio, Servicios, Contacto*) con llamadas a la acción (CTA) claras.
* **Optimización de Recursos Digitales:** Gestión y compresión de componentes multimedia y APIs nativas del CMS para asegurar un rendimiento de carga óptimo.

## Instrucciones de Ejecución
1.  Instala una instancia de WordPress en un servidor local (Local WP, XAMPP) o en un hosting en producción.
2.  Instala y activa el tema `Sunbrake` junto al plugin de maquetación `Kubio`.
3.  Importa el archivo de respaldo (`.wpress` o archivo XML de base de datos) provisto en este repositorio.
4.  Navega por las secciones usando el menú superior autogestionable.

## Reflexión Personal

### ¿Qué aprendí?
Aprendí el enorme valor operativo de las herramientas *Low-Code* profesionales. Descubrí cómo estructurar de forma clara y atractiva un perfil profesional de Ingeniería de software y cómo optimizar la usabilidad (UI) del sitio.

### ¿Qué fue difícil?
Alinear ciertos componentes avanzados del constructor visual Kubio para que mantuvieran una simetría perfecta y responsiva en pantallas de dispositivos móviles con resoluciones muy reducidas.

### ¿Qué mejoraría?
Integraría herramientas de analítica web (como Google Analytics) para rastrear las visitas al portafolio y añadiría una sección de blog técnico para publicar artículos sobre desarrollo de software.
