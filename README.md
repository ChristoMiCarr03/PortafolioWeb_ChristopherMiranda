Descripcion General
Este portafolio es un espacio digital que compila mis mejores trabajos, evidencias de proyectos reales y simulaciones de entornos de software. El objetivo principal es demostrar mi evolución técnica, mi capacidad para adoptar arquitecturas modernas y mi enfoque en la creación de soluciones eficientes, limpias y escalables para el sector tecnológico y de gestión.

Tecnologías Utilizadas

Para el desarrollo de los proyectos incluidos en este portafolio, se empleó un stack tecnológico robusto que abarca desde tecnologías de desarrollo de software hasta herramientas de gestión de aprendizaje y control de versiones:

* **Backend & Lenguajes:**
    * **PHP:** Lenguaje principal utilizado para la lógica del servidor, conexiones PDO y estructuración de aplicaciones dinámicas bajo la arquitectura MVC.
* **Frontend:**
    * **HTML5 / CSS3:** Estructuración y diseño visual de interfaces de usuario web limpias, accesibles y responsivas.
* **Plataformas & Herramientas de Gestión:**
    * **Moodle:** Configuración, administración y personalización de entornos virtuales de aprendizaje (LMS).
* **Control de Versiones & Despliegue:**
    * **GitHub / Git:** Gestión del código fuente, control de versiones, flujos de trabajo en ramas y respaldo de repositorios.
 
Competencias Desarrolladas

A través de la realización de estos proyectos, he fortalecido y consolidado las siguientes competencias profesionales:

1. **Desarrollo Backend Avanzado:** Diseño e implementación de arquitecturas web utilizando el patrón Modelo-Vista-Controlador (MVC), asegurando la separación de responsabilidades y un código mantenible.
2. **Modelado y Gestión de Bases de Datos:** Creación de diagramas Entidad-Relación (ER), normalización de datos e implementación de consultas seguras mediante PDO para sistemas de inventario y almacenamiento especializado.
3. **Planificación y Gestión de Proyectos:** Aplicación de metodologías de trabajo estructuradas, incluyendo la asignación de responsabilidades mediante matrices RACI, definición de fases de desarrollo y cronogramas.
4. **Análisis Estratégico de Negocios:** Capacidad para evaluar entornos operativos mediante matrices FODA (SWOT), definición de Indicadores Clave de Rendimiento (KPIs) y mapas estratégicos aplicados a negocios locales.
5. **Autonomía y Aprendizaje Continuo:** Habilidad para adoptar nuevas tecnologías, frameworks y plataformas para resolver problemas del mundo real de manera eficiente.

Lista de Proyectos Incluidos

### Proyecto 1: AgriMEWA – Sistema de Gestión de Inventario Agrícola
* **Descripción:** Sistema modular diseñado para la administración y control de inventarios en entornos agrícolas, enfocado en el registro y trazabilidad de semillas y medicamentos veterinarios. Cuenta con módulos de inicio de sesión seguro, catálogos dinámicos y gestión de entradas/salidas.
* **Tecnologías:** PHP (MVC), PDO, MySQL, HTML5, CSS3, Git.

### Proyecto 2: Análisis Estratégico y Plan Operativo – Taller Mecánico
* **Descripción:** Consultoría técnica y análisis estratégico integral para el taller mecánico "El Chino Martínez". Incluye el desarrollo de una matriz FODA, el diseño de un mapa estratégico y el establecimiento de KPIs para optimizar la productividad del negocio.
* **Tecnologías:** Herramientas de Análisis de Negocio, Documentación Técnica.

### Proyecto 3: Plan de Proyecto y Matriz RACI – Taller de Emprendedores
* **Descripción:** Estructuración metodológica y académica de un plan de proyecto para un taller de emprendimiento. Incluye la definición analítica de fases, cronograma de actividades y el diseño de una matriz RACI para delegar roles y responsabilidades de manera óptima.
* **Tecnologías:** Gestión de Proyectos, Matrices de Responsabilidad.

### Proyecto 4: Gestión de Entornos Virtuales y Soporte de TI
* **Descripción:** Configuración y administración de plataformas de aprendizaje (Moodle) y documentación del impacto social y técnico, basado en la culminación de 500 horas de servicio comunitario enfocado en el soporte tecnológico en entornos educativos (Escuela Primaria Dolores Correa Zavala).
* **Tecnologías:** Moodle, Documentación de TI, Gestión de Contenidos.
